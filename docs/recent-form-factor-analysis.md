# 近期状态因子的样本限制与优化建议

## 背景

当前预测功能中包含“近期状态”因子，主要基于球队最近比赛表现进行方向判断。项目当前可获取的近期状态数据通常最多为 15 场比赛。

这个样本规模较小，因此不适合将近期状态当作强统计结论使用。它更适合作为辅助信号或修正项，用于识别球队是否明显偏离正常状态，而不是单独决定预测方向。

## 核心问题

近期状态最多只有 15 场，存在以下问题：

1. 样本数量少，随机波动大。
2. 不同对手强弱差异会显著影响结果。
3. 主客场差异会放大或削弱近期表现。
4. 杯赛、轮换、伤停、赛程密度会造成短期状态失真。
5. 只看胜平负容易误判亚盘方向。
6. 连胜或连败容易被过度解释。

因此，近期状态不能作为高权重核心因子，更不能直接转化为高置信度结论。

## 因子定位

建议将近期状态定义为：

- 辅助因子。
- 弱信号。
- 状态偏离检测因子。
- 风险修正因子。

不建议将近期状态定义为：

- 核心方向因子。
- 高权重因子。
- 独立决策因子。
- 直接决定置信度的主要来源。

## 权重建议

当前“近期状态”权重为 `1.5`。

建议：

- 保守方案：保留 `1.5`，但限制最高得分。
- 更稳方案：降到 `1.0`。
- 如果后续加入更多市场量化因子，近期状态权重应低于亚盘、欧赔、临场变化、多公司一致性。

推荐权重排序：

| 因子 | 建议角色 | 权重建议 |
| --- | --- | ---: |
| 亚盘多公司一致性 | 核心因子 | 2.5-3.0 |
| 欧赔隐含概率变化 | 核心因子 | 2.0-2.5 |
| 临场盘口变化 | 核心因子 | 2.0-3.0 |
| 近期赢盘率 | 辅助因子 | 1.0-1.5 |
| 近期胜平负/净胜球 | 辅助因子 | 0.8-1.2 |
| 交锋历史 | 弱辅助因子 | 0.5-1.0 |
| 单关/热度 | 风险修正因子 | 不建议独立高权重 |

## 不建议只看胜平负

15 场样本下，单纯胜率并不稳定。建议拆成多个更细的状态特征。

### 可量化特征

| 特征 | 含义 |
| --- | --- |
| `recent_points_5` | 近 5 场积分 |
| `recent_points_10` | 近 10 场积分 |
| `recent_points_15` | 近 15 场积分 |
| `goal_diff_5` | 近 5 场净胜球 |
| `goal_diff_10` | 近 10 场净胜球 |
| `goals_for_10` | 近 10 场进球 |
| `goals_against_10` | 近 10 场失球 |
| `cover_rate_5` | 近 5 场赢盘率 |
| `cover_rate_10` | 近 10 场赢盘率 |
| `home_recent_form` | 主队主场近况 |
| `away_recent_form` | 客队客场近况 |

其中，亚盘预测更应关注：

- 赢盘率。
- 净胜球。
- 主客场状态。
- 对手质量。

胜平负只能作为辅助信息。

## 时间衰减

近期状态不应把 15 场平均看待。越近的比赛参考价值越高。

建议使用时间衰减：

| 区间 | 权重 |
| --- | ---: |
| 最近 1-5 场 | 50% |
| 最近 6-10 场 | 30% |
| 最近 11-15 场 | 20% |

示例：

```text
weighted_form =
  form_last_5 * 0.50 +
  form_6_to_10 * 0.30 +
  form_11_to_15 * 0.20
```

如果只有 5 场或 10 场数据，应按实际样本重新归一化权重。

## 回归均值处理

小样本容易出现极端结果。例如某队近 5 场全胜，并不代表真实强度显著提升。

建议对近期状态做回归均值处理：

```text
adjusted_form = recent_form * sample_weight + baseline_form * (1 - sample_weight)
```

其中：

- `recent_form` 是近期状态指标。
- `baseline_form` 是基准表现，可以先用中性值或联赛平均值。
- `sample_weight` 根据样本数变化。

示例：

| 样本数 | recent_form 权重 | baseline 权重 |
| ---: | ---: | ---: |
| 1-3 场 | 30% | 70% |
| 4-7 场 | 50% | 50% |
| 8-12 场 | 65% | 35% |
| 13-15 场 | 75% | 25% |

这样可以避免少量比赛导致过度自信。

## 对手强度修正

近期 10 场 7 胜，如果对手整体较弱，参考价值有限。建议增加对手强度修正。

如果没有完整 ELO 或长期数据库，可以先使用粗略特征：

| 修正项 | 说明 |
| --- | --- |
| 对手排名 | 对手排名越高，比赛含金量越高 |
| 联赛级别 | 跨级别杯赛结果应谨慎处理 |
| 主客场 | 主场强势不等于客场强势 |
| 当场盘口 | 大幅让球取胜和受让取胜含义不同 |
| 对手近期状态 | 击败低迷球队的含金量较低 |

简化做法：

```text
quality_adjusted_result = match_result_score * opponent_strength_factor * venue_factor
```

在数据不足时，对手强度修正可以先只做等级化：

- 强队。
- 中游。
- 弱队。
- 低级别球队。

## 得分上限建议

由于样本少，近期状态即使表现很好，也不应轻易给高分。

建议限制：

| 条件 | 最高分建议 |
| --- | ---: |
| 只有胜平负优势 | 6 |
| 胜平负和净胜球都占优 | 7 |
| 胜平负、净胜球、赢盘率均占优 | 8 |
| 同时主客场匹配且对手质量不弱 | 8 |
| 数据不足 5 场 | 6 |
| 数据不足 3 场 | 5 |

不建议近期状态单因子给到 `9-10`，除非后续有更完整的长期数据和对手强度模型。

## 推荐计算框架

建议将近期状态拆为两个子因子：

### 1. 近期竞技状态

关注球队真实比赛表现：

- 近 5/10/15 场积分。
- 近 5/10 场净胜球。
- 进球和失球趋势。
- 主客场分拆。

输出：

```text
recent_performance_score: 0-1
```

### 2. 近期赢盘状态

关注亚盘相关表现：

- 近 5/10 场赢盘率。
- 近 5/10 场输盘率。
- 类似盘口下赢盘情况。

输出：

```text
recent_cover_score: 0-1
```

最终近期状态：

```text
recent_form_score =
  recent_performance_score * 0.4 +
  recent_cover_score * 0.6
```

原因：

- 亚盘预测更贴近赢盘结果。
- 胜平负表现仍有价值，但不能主导。

## 在最终预测中的使用方式

近期状态建议只作为辅助项：

```text
final_score =
  market_score * 0.65 +
  form_score * 0.15 +
  matchup_score * 0.10 +
  risk_adjustment * 0.10
```

其中：

- `market_score` 包含亚盘、欧赔、临场变化、多公司一致性。
- `form_score` 包含近期状态和近期赢盘率。
- `matchup_score` 包含交锋和实力定位。
- `risk_adjustment` 包含单关、热度、数据质量、市场分歧。

这样可以避免近期状态小样本对最终结果产生过大影响。

## 置信度处理建议

近期状态不应直接拉高置信度。

建议规则：

- 近期状态与市场因子同向时，小幅增加置信度。
- 近期状态与市场因子反向时，降低置信度或标记风险。
- 只有近期状态强而市场因子不支持时，不输出强信号。
- 数据不足时，不因近期状态提高置信度。

示例：

| 场景 | 处理 |
| --- | --- |
| 市场强信号 + 近期状态同向 | 置信度小幅增加 |
| 市场强信号 + 近期状态反向 | 置信度降低 |
| 市场弱信号 + 近期状态强 | 最多中等信号 |
| 市场无信号 + 近期状态强 | 不建议高置信输出 |
| 近期数据不足 | 近期状态置为中性或低权重 |

## 总体建议

近期状态不是不能用，而是不能过度使用。

合理定位是：

1. 用来识别球队短期是否明显偏离正常表现。
2. 用来辅助确认市场方向。
3. 用来降低与市场矛盾时的置信度。
4. 不单独决定预测方向。
5. 不单独制造高置信度。

下一步更合理的预测体系应以市场量化因子为核心：

- 亚盘多公司一致性。
- 欧赔隐含概率变化。
- 临场盘口变化。
- 盘口离散度。

近期状态作为辅助：

- 近期赢盘率。
- 净胜球趋势。
- 主客场状态。
- 对手强度修正。

这样既能使用现有 15 场以内的数据，又能避免小样本导致的过度判断。
